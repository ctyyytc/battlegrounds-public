# Battlegrounds Public

这是一个战棋玩法的非官方核心实现与改进项目。当前源码版本为 **14.5.0**，对应 14.0 大版本阶段收口。本仓库从审查后的文件白名单建立独立提交历史，面向代码阅读、规则研究与后续开发。

**这是核心源码归档，不能直接运行完整游戏。** 所有视觉文件及导入元数据均未随仓库分发，包括默认占位图、自制界面和关键词特效纹理；源码仍可能引用这些省略的文件。本仓库不承诺下载即可玩，也不附引擎二进制或可执行发行包。

## 内容

| 目录 | 用途 |
| --- | --- |
| `battlegrounds/domain/` | 规则、状态、随机流、存读和资源加载逻辑 |
| `battlegrounds/ui/`、`battlegrounds/app/` | 界面与应用入口源码，视觉依赖另行准备 |
| `battlegrounds/content/` | 功能定义、兼容编号和默认占位数据 |
| `battlegrounds/resource_contract/` | 外部图文/基础数值字段与图片键的中性接口 |
| `battlegrounds/tools/` | 离线内容包模板/检查与本地子集复制工具 |
| `battlegrounds/examples/` | 不含原版图文的空内容包示例 |

源项目使用 Godot 4.x；这里保留的应用名和用户数据目录 `battlegrounds-o` 用于隔离本地数据。仓库文件统一放在 `battlegrounds/`。软件许可见 [LICENSE](LICENSE)，依赖和素材边界见 [THIRD_PARTY_NOTICES.md](THIRD_PARTY_NOTICES.md)。

## 外部内容接口

从仓库根目录可运行以下离线工具；需要 Python 3.10 或更新版本，仅使用标准库，不联网下载内容：

```sh
python battlegrounds/tools/resource_pack.py template --output my-pack
python battlegrounds/tools/resource_pack.py check --pack my-pack/pack.json
```

模板使用默认占位数值及空显示字段，不还原原版图文或原始数值包。外部资源由使用者自行准备，并应具有相应使用权。内容包导入不补齐本仓库省略的全部内置视觉依赖；恢复可运行工程需要另行完成这些资源的准备与验证。接口说明见 [RESOURCE_PACKS.md](battlegrounds/RESOURCE_PACKS.md)。

## 当前行为与验证边界

最终源码包含全英雄手选/三选一的开始流程、统一设置、饰品可选机会提醒、每轮开始选择链完成后保存、最近三项完整招募操作的滚动撤销，以及相应规则修补。设置沿用原暂停状态，使用次数不限的撤销仍受回合/阶段边界限制。

完整来源工程在固定 14.5.0 上有八组、522 项选定独立检查通过的记录，包含对应英雄技能追加和跨进程存读代表；该结果属于原固定来源与具名范围，不能直接外推为本公开子集的运行认证。公开子集仅验证文件身份、公开范围和离线工具。没有对本子集执行 Godot 启动、完整自然局、全内容组合或完整资源包安装卸载界面矩阵。

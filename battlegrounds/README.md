# 核心源码 14.5.0

此目录是按明确白名单保存的核心源码子集。仓库整体说明见 [README](../README.md)，代码许可见 [LICENSE](../LICENSE)。

规则和功能数据来自固定的 14.5.0。仅在副本中去掉本机开发插件的启用项；规则代码不为发布而改写。默认显示名称为兼容 ID，卡牌正文留空，缺少外部内容时使用中性占位字段。

**视觉资源全部省略，本目录不能直接作为完整游戏启动。** 包括 `project.godot` 和界面中的部分 `res://assets/` 路径仍指向未分发的视觉依赖。它们是接口/代码引用，仓库没有对应原图附件。准备可运行版本时须补齐合法资源并单独验证。

`PUBLIC_FILES.json` 描述此核心子集，既不包含私有工程历史，也不意味着完整发行物已验收。`tools/public_copy.py --output 新空目录` 只复制此清单已有文件，不能补回缺失视觉素材，不会上传或发布。

本仓库未携带完整开发测试工具与原始证据。离线资源包工具的用法见 [RESOURCE_PACKS.md](RESOURCE_PACKS.md)；公开子集的实际验证范围见仓库根 README。
